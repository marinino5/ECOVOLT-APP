## 🌱 Descripción del proyecto

**ECOVOLTAPP** es una aplicación móvil desarrollada en Android como proyecto final de la asignatura **Tecnologías Móviles**.

La app está orientada a representar un sistema de alquiler de transporte eléctrico bajo la marca **Ecovolt**, permitiendo simular una solución digital enfocada en movilidad sostenible, acceso práctico a vehículos eléctricos y una experiencia de usuario sencilla e intuitiva.

Este proyecto busca aplicar conceptos fundamentales del desarrollo móvil mediante la creación de una aplicación funcional, organizada y visualmente coherente con la identidad de la marca Ecovolt.

## ⚡ Enfoque del proyecto

**Ecovolt** propone una experiencia digital orientada a la movilidad eléctrica, práctica y sostenible.  
La aplicación busca representar de manera académica cómo un usuario podría acceder a un servicio de alquiler de transporte eléctrico desde una app móvil.
